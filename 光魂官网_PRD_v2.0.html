1 · 背景与目标

品牌口径统一为 光魂（光魂科技 / 小雪人数码，SUPER DISPLAY CO），内容以 显示器为主 + 少量周边；实测口径为 小雪人评测实验室（标注来源 / 样本量 / 方法版本）。

目标：先把「体验细节、视觉规范、SEO 与后台可用性」打底，为后续逐模块大改造（v2.1）铺路；前后台一一对齐。

2 · v2.0 已实现

2.1 UI 规范

项说明
圆角收敛令牌 --gh-radius-{sm,md,lg,xl,2xl} 调整为 4/6/8/10/14
区块标题图标SectionHead 支持 icon；新增 BlockIcon；首页各区块标题配图标
媒体槽规则有素材显示素材；无素材以 代码渐变兜底（CodeMedia）；首屏第一张海报为特例，固定 canvas 代码动画（CodeBackdrop）

2.2 导航与顶栏

  • 一级项改名：Center 软件 → 光魂 Center；文章 → 评测与资讯。
  • 角标支持自定义文案（SiteLink.badgeText），后台「站点配置」可填。

2.3 页脚

  • 新增社交关注（微信 / 微博 / B 站 / 抖音）。
  • 二维码改为视觉仿真（定位角 + 定时图案 + 伪随机模块）。

2.4 首页

  • 顺序：重点产品提到「按场景选择」之前。
  • 标题与图标：实测天梯榜 / 评测与解析 / 服务与支持 / 体验与合作。
  • 「按场景选择」卡片链接改为 /products?scene=xxx。
  • 「评测与解析」限定内容类（不含新闻）；服务四卡分别指向 support / downloads / faq / contact；体验点卡补链接。

2.5 产品 / Center

  • 详情主 CTA 改为 预约体验，次 CTA「加入对比」；咨询咨询师 → 在线顾问。
  • Center 页文案改显示器语境；「立即下载」指向 /downloads。

2.6 SEO

新增 scripts/gen-seo.ts：由 meta.ts 真源生成 sitemap.xml / robots.txt，npm run gen:seo 一键同步。Product / FAQ 结构化数据列入 v2.1。

2.7 后台

新手指导扩到 8 步：导航 → 页面装修 → 产品维护 → 素材上传 → 咨询工单 → 样式与模板 → 站点配置 → 发布回滚；每步可一键跳转。

3 · 未实现（v2.1 计划） 计划

  1. 重点产品重构（方案二优化版：上下布局 + 浅底信息区 + 图标规格条 + 3 条卖点 + 进度点/箭头）。
  2. 天梯榜：领奖台 + 列表 + 缩略图 + 四项交互 + 我的型号高亮 + 页内测试方法入口。
  3. 评测与资讯：分类改方案 C（评测/教程/技术/资讯）+ 主题标签；详情 TOC / 相关产品 / 作者来源 / 分享。
  4. 服务支持：下载精选 + 类型/型号筛选；服务承诺条；型号支持入口；保修可维护 + 锚点；FAQ 分类。
  5. 商业合作：合作流程 / 权益 / 品牌资料下载；案例卡带图 + 成果数据；体验点补全。
  6. 关于 & 品牌：媒体报道·荣誉；光魂实验室区块；招聘投递；品牌页主视觉（区块化）。
  7. 登录 & 个人中心：验证码 / 记住我 / 密码可见与强度 / 同意条款 / 登录设备管理；设备关联资料 / 收藏 / 订阅分粒度 / 注销 / 工单附件+评价 / 设备登记+保修提醒。
  8. 后台新栏目：服务评价、设备登记、迭代需求池（看板 + MoSCoW + 版本 + 四象限）；工作台待办；站点配置新增；表单提示规范。
  9. 工程与运营：筛选全量进 URL / 对比只看差异 / 404 搜索 / 公告定时 / 埋点 / 内容导出导入 / 表单反垃圾 / 出图与图片规范。
  10. 需求池登记：第三方登录、短信、SN 解析、购买渠道、多语言覆盖提示。

4 · 数据模型与接口变更

  • SiteLink 新增 badgeText?: string（角标自定义文案），后端 / 前端类型同步。
  • 媒体槽：MediaImg 对「空值 / # / /media/** / 加载失败（无 variant）」统一回退 CodeMedia。
  • SEO：public/sitemap.xml、public/robots.txt 改为生成产物（勿手改）。
