## 三、代码仓库

| 子项目 | 技术栈 | 职责 |
|---|---|---|
| `gh-web/` | React 19 + Vite 8 + TS（react-router-dom 7） | 前台 + 后台（同一应用，`/admin/*` 路由树） |
| `gh-server/` | Express 5 + TS + tsx | 内容库、结构化集合、上传、后台鉴权、数据聚合 |

**数据持久化**（均在 `gh-server/data/`）：**SQLite 单库 `gh.sqlite`**（内容库 / 结构化集合 / 后台资源 / 审计日志，阶段 5a 起；启用 WAL，含 `-wal`/`-shm`）、`uploads/`（素材）；旧的 `content-store.json` / `collection-store.json` / `admin-resources.json` / `audit-log.json` 仅作**一次性迁移来源**（保留不删）。

## 四、快速上手

```bash
# 后端
cd gh-server && npm ci && npm start          # http://localhost:8787
# 前端（本地开发，同源经 dev proxy 转发到 8787）
cd gh-web && npm ci && npm run dev
# 生产构建（同源部署）
cd gh-web && VITE_API_BASE= npm run build
# 同源托管（后端一并提供前端）
cd gh-server && npm run serve
```

- 后台入口：`/admin`（种子账号 `admin/admin123`、`operator/oper123`；**鉴权已加固**：scrypt 加盐哈希 + httpOnly Cookie + CSRF 来源校验 + 服务端 RBAC，生产务必改默认口令）。
- 部署与上线：见 [`光魂官网_部署Runbook_v1.0.md`](./文档/光魂官网_部署Runbook_v1.0.md)。
