1 · 背景与目标

品牌口径统一为 光魂（光魂科技 / 小雪人数码，SUPER DISPLAY CO），内容以 显示器为主 + 少量周边；实测口径为 小雪人评测实验室（统一标注来源 / 样本量 / 方法版本）。

目标：把「体验细节、视觉规范、SEO、后台可用性」打底，并 逐模块完成前台大改造与后台配套；前后台一一对齐——前台每个可维护点，后台都有对应入口 / 字段，后台改动即时反映到前台，不脱节。

交付原则：全量过代码并补中文注释（文案 / 尺寸 / 阈值 / 校验规则 / 颜色与圆角 token / 接口契约），便于后续手动修改。

3 · 分模块实现明细

3.1 UI 规范与视觉

项说明
圆角收敛设计令牌 --gh-radius-{sm,md,lg,xl,2xl} 调整为 4/6/8/10/14，观感更利落
区块标题图标SectionHead 支持 icon；新增 BlockIcon（名称 → 线性图标）；首页各区块标题配图标
数据表达数据卡统一「图标 + 单位 + 趋势 + 说明」的表达位，不再裸数字
媒体槽规则媒体位 有素材显示素材（图片 / 视频 / GIF）；无素材以「代码渐变 / 代码动画」兜底（CodeMedia），不再使用占位图；首屏第一张海报为特例，固定 canvas 代码动画（CodeBackdrop）；场景模块保持左右滑动（rail：拖拽 + 边缘自动推进 + 箭头）
移除 AI 生成图此前的显示器 / 场景占位图全部移除，改用代码背景 / 真实素材

3.2 导航与顶栏

  • 一级 7 项：产品 / 光魂 Center（角标 NEW）/ 天梯榜 / 评测与资讯 / 服务支持 / 商业合作 / 关于光魂。
  • 角标升级为 可自定义文案（SiteLink.badgeText），支持 摇动；后台「站点配置」可填。
  • 产品面板：总览 + 4 系列 + 按场景选（URL 驱动 ?scene=）。
  • 天梯面板：榜单（综合 + 3 系列）+ 热门条目（响应 / 亮度 / 色准）+ 页面内测试方法入口。
  • 评测与资讯面板：内容（全部 / 评测 / 教程 / 技术解析）+ 动态（新闻中心 / 品牌动态）。
  • 服务面板：服务支持 / 下载中心 / 型号支持 / 常见问题 ‖ 提交咨询 / 联系我们 / 保修与售后（页内锚点 #warranty）。
  • 顶栏新增：公告条（后台可配、可关闭、可定时上下线）+ 购买 / 预约体验 CTA + 内页面包屑（联动 JSON-LD BreadcrumbList）。

3.3 首页

  • 区块顺序：首屏海报 → 重点产品 → 按场景选择 → 天梯榜 → 技术评测 → 数据一览 → 服务入口 → 服务承诺条 → 选购指南 → 固件更新卡 → 精选 FAQ → 合作·体验点 → 订阅（默认开启） → 新闻 → 联系。
  • 首屏下方加 信任条（实测徽标 / 合作 logo）；「技术评测」限定评测 / 教程 / 技术解析（不含新闻）。
  • 服务入口 4 卡链接各就各位（/support、/downloads、/faq、/contact）；体验点卡补链接。

3.4 重点产品（详情 / 列表 / 对比）

  • 重点产品模块重构为方案二优化版：上下布局（媒体 16:10、左对齐）+ 浅底信息区（左：型号 / 名称 / 价格 / 双 CTA / 翻页进度点+箭头；右：带图标规格条 + 3 条卖点）；去掉卖点圆角框；排版干净、高级、整洁、大气。
  • 详情页主 CTA = 预约体验，次 CTA = 加入对比；咨询咨询师 → 在线顾问。
  • 详情页新增：图集（含视频 / GIF） + 相关 FAQ + 实测对比条（区块，后台可开启 / 关闭）。
  • 「相关产品」改为 同系列 / 同价位；列表页加 对比勾选 + 底部对比浮条；筛选全量进 URL。

3.5 天梯榜

  • 版式：领奖台（前三）+ 列表，每行 带产品缩略图。
  • 交互：指标切换实时重排名次 / 条形生长动画 / ↑↓ 名次变化 / hover 展开实测小卡。
  • 小功能：我的型号高亮 + 页面内测试方法入口；不新增参数指标，实测数据统一标注来源 / 样本量 / 方法版本。

3.6 评测与资讯

  • 分类口径采用 方案 C：类别 = 评测 / 教程 / 技术 / 资讯（MECE）；另有 主题标签维度（OLED / 双模高刷 / 响应与拖影 / 色彩与色准 / 接口与带宽 / 软件与固件 / 赛事与活动）。
  • 「新闻中心」= 资讯类聚合页；列表卡片 带缩略图；筛选进 URL。
  • 详情页新增：目录 TOC + 文末相关产品 + 作者与来源块 + 分享。

3.7 服务支持

  • 支持首页下载区只放 精选 4 条 + 查看全部（完整列表在 /downloads）。
  • 下载中心筛选：类型（说明书 / 固件 / 驱动 / 软件 / 调校配置）+ 型号；卡片显示版本 / 大小 / 更新日期。
  • 新增：服务承诺条 / 型号支持索引（/support/models，聚合全部已收录型号 → /support/model/:id） / 保修与售后（可维护条目 + 锚点 #warranty） / FAQ 分类（安装 / 连接 / HDR / 售后）。
  • 快速入口卡、联系卡补链接（tel: / mailto: / 在线工单）。

3.8 商业合作

  • 新增：合作流程（提交 → 对接 → 落地） / 合作权益（渠道 / 赛事 / 内容 / 联名） / 品牌资料可下载。
  • 案例卡片：封面图 + 行业 / 规模标签 + 成果数据（选填）。
  • 体验点详情：地址 + 营业时间 + 电话 + 预约体验 CTA（字段 选填，缺失不渲染）。

3.9 关于 & 品牌

  • 关于页「新闻中心」块 → 改为 媒体报道 · 荣誉。
  • 新增：光魂实验室（区块，可切 图文流程 / 时间轴 / 数据看板）/ 招聘投递 / 品牌页主视觉（区块化：大图 + 标语 + 关键数据 + CTA，可装修）。
  • Center 软件页改造：文案改显示器语境（色彩 / 亮度 / HDR / 刷新 / 校色 / 固件），「立即下载」指向真实软件下载。

3.10 登录 / 注册 & 个人中心

  • 登录 / 注册补：图形验证码 / 记住我 / 密码可见切换 / 密码强度提示 / 同意条款勾选（合规） / 登录设备管理（退出全部设备）。
  • 登录页左栏 = 品牌主张 + 最新动态 / 实测数据，底部海报图作背景。
  • 个人中心增强：设备关联资料（型号 → 说明书 / 固件 / FAQ）/ 收藏产品 + 文章（一键加对比）/ 订阅分粒度（新品 / 固件 / 活动）/ 注销账号 / 通知与订阅联动 / 工单附件 + 服务评价 / 设备登记 + 保修到期提醒。
  • 保修规则：起始日以 购买日期 为准；SN 选填、暂不解析（留开关位）；三年质保（含烧屏保护），到期前 30 天 提醒（年限 / 提醒天数后台可配）。

3.11 后台

  • 新增栏目：服务评价、设备登记（设备管理）、迭代需求池（归入「系统设置」组）。
  • 迭代需求池 = 进阶档：列表 + 看板视图 + MoSCoW 优先级 + 版本（Roadmap） + 影响 × 成本四象限；分类六类；来源 = 本次预置 + 手动新增 +（后续）一键转入。
  • 工作台加待办聚合：待处理咨询 / 待评价 / 待审核 + 快捷入口（计数由服务端聚合）。
  • 站点配置新增：公告条（文案 / 链接 / 可关闭 / 定时上下线）、顶栏 CTA、验证码与第三方登录开关（第三方仅留开关位）、保修参数（年限 / 提醒天数 / SN 解析开关）。
  • 表单可用性规范：字段 = label + 浅灰小字说明（用途 / 示例）+ 占位示例 + 即时校验（内联提示，不弹窗）；上传类注明 支持格式 / 大小上限，不合规当场提示。
  • 装修器新增：区块「页内锚点」（style.anchor，前后端双重 sanitize → <section id>，支持 /path#anchor 深链）。
  • 备份栏目扩展：创建 / 下载 / 恢复 / 删除 / 重置之外，新增 内容一键导出 JSON / 导入还原（导入前自动留 pre-import 快照）。
  • 新手指导扩到 8 步：导航 → 页面装修 → 产品维护 → 素材上传 → 咨询工单 → 服务评价 → 迭代需求池 → 站点配置与发布；首次自动触发、可重开、可跳过 / 返回。

3.12 页脚

  • 新增 社交关注（微信 / 微博 / B 站 / 抖音）。
  • 二维码 视觉真实化（官方微信 / 公众号）；手机端页脚手风琴折叠。

3.13 工程与运营

项说明
SEO 基建sitemap.xml + robots.txt 由 meta.ts 真源 生成（npm run gen:seo）；结构化数据 Organization / WebSite / WebPage / BreadcrumbList / Product / FAQ；每页唯一 H1
图片与性能上传时 Canvas 生成 320/640/1280 WebP 变体并登记 srcset；尺寸 / alt 规范；首屏懒加载 + 骨架屏；代码动画 reduced-motion / 低端机降级
表单反垃圾咨询 / 订阅 / 合作等 公开表单 统一：限流 + 图形验证码 + 蜜罐字段（formGuard + CaptchaField）
体验细节产品筛选全量进 URL；对比页「只看差异」；404 搜索引导；公告条定时上下线
事件埋点CTA / 下载 / 预约 / 对比 / 订阅 点击埋点（/api/track/view、/api/track/download、/api/track/event）+ 后台报表（纯自建）
定时发布内容 / 公告支持预约到指定时间自动上线 / 下线（publishScheduleStore + 常驻调度器）
内容导出 / 导入全站内容一键导出 JSON / 导入还原（复用备份模块的 snapshot() / restoreSnapshot()，导入前自动留快照）

4 · 数据模型与接口变更

  • SiteLink 新增 badgeText?: string（角标自定义文案），后端 / 前端类型同步。
  • BlockStyle 新增 anchor?: string（页内锚点），前端渲染为 <section id>，后端保存时 sanitize。
  • SiteConfig 扩展：announcement（公告条）、cta（顶栏 CTA）、auth（验证码 / 第三方开关）、warranty（年限 / 提醒天数 / SN 解析）。
  • 媒体槽：MediaImg 对「空值 / # / /media/** / 加载失败」统一回退 CodeMedia。
  • SEO：public/sitemap.xml、public/robots.txt 改为 生成产物（勿手改）。
  • 新增公开端点：GET /api/captcha（图形验证码）。
  • 新增后台端点：GET /api/admin/content/export、POST /api/admin/content/import。
  • 埋点端点：POST /api/track/view、/api/track/download、/api/track/event（公开，无需登录）。
