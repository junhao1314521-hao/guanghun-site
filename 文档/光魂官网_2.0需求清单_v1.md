## 0. 总原则（贯穿全部）

1. **功能与模块不删减**：不要的用后台「启用 / 停用 / 隐藏 / 删除」调控，不再靠改代码删功能
2. **新增功能不得把后台搞乱**：同类配置共用同一套控件，遵守后台既有控件规格（尺寸 / 间距 / 圆角 / 暗色主题），不各写一套
3. 停用某个区块后，**下面的模块自动上移**，不留空位

### 1.2 首屏海报
| 项 | 确定内容 |
|---|---|
| 张数 | 保留 **3 张轮播**（不是只剩 1 张） |
| 代码动画 | **保留不动**（第 1 张） |
| 文字层次 | **大标题 + 一句话 + 按钮**（三层）；**眉题、卖点/数据点改为「开关」可选**，关掉就不显示 |
| 卖点展示 | 开关打开时按**一行小字**展示（如 `540 Hz · 0.03 ms · 80 Gbps`），不做三块并列 |
| 按钮 | 后台可配 **1 或 2 个**；首屏默认 **1 个「立即购买」** |
| 控件 | **只留底部圆点**（箭头、页码都不显示） |
| 文案位置 | **九宫格 9 档**（左/中/右 × 上/中/下）**＋ 可拖拽到任意位置**；两者写同一个字段（百分比坐标） |
| 手机端位置 | 默认**跟随桌面位置**；超出安全区的自动吸附回最近的九宫格位 |
| 媒体支持 | 图片 / 视频 / GIF / 代码动画 |
| 背景主题 | 暗色 / 浅色（沿用现有） |

### 1.3 五张全屏海报
| 项 | 确定内容 |
|---|---|
| 形态 | **一张海报 = 一个区块**，可增 / 删 / 上下移 / 停用；**不是轮播**，五张各自独立各占一屏 |
| 数据 | **不关联产品**；「立即购买」等链接**手工填写** |
| 复用 | 与首屏海报**共用同一套字段与位置控制**（后台只学一套海报编辑器） |
| 高度 | **模块内可设档位**，档位里必须包含「比首屏矮一档」 |
| 按钮 | 默认 **2 个**（`进一步了解` + `购买`，按你的截图）；可增减 |

**海报模块字段（首屏与五张海报共用）**

| 字段 | 必填 | 说明 |
|---|---|---|
| 媒体 | 是 | 图片 / 视频 / GIF / 代码动画 |
| 大标题 | 是 | 如 `God 60 标准款` |
| 一句话 | 是 | 如 `八面出锋 大巧不工` |
| 眉题 | 否 | 开关控制 |
| 卖点 / 数据点 | 否 | 开关控制，默认一行小字 |
| 按钮① | 是 | 文字 + 链接 |
| 按钮② | 否 | 文字 + 链接；留空则只显示 1 个 |
| 文案位置 | 是 | 九宫格 9 档 或 拖拽 |
| 高度 | 五张海报用 | 满屏 / 矮一档 / 自定义（首屏固定满屏） |
| 背景主题 | 是 | 暗色 / 浅色 |

### 1.4 2×2 产品矩阵（**新建独立区块**）
| 项 | 确定内容 |
|---|---|
| 区块 | **单独做一个「产品矩阵」区块**（不复用现有「产品」区块） |
| 卡面 | 图片铺满整张卡；**型号 + 一句话 + 按钮悬浮在图片右下角**（半透明面板，保证可读） |
| 按钮 | 可增减（默认 1 个 `立即购买`） |
| 数据源 | **两种都支持**：① 关联产品（自动带入产品主图、型号、详情链接；文案可覆盖）② 手填（自己传图、填型号、填链接） |
| 张数 / 列数 | 2×2（默认） / 3 列 / 4 列 |
| 图片比例 | 16:9（默认） / 1:1 / 3:4 |
| 满屏 | 开 = 一屏正好放下四张 |
| 裁切焦点 | 居中 / 上 / 下 / 左 / 右（同一张图裁切，不变形） |
| 手机端排列 | **横向滑动（默认）** / 保持 2×2 |
| 手机端单独传图 | 选填，留空沿用桌面图 |
| 点击 | 点卡片 / 型号 → 产品详情页；点按钮 → 按钮自配链接 |

### 1.5 固件驱动
- 形式：**保持 3 张卡**（固件 / 驱动 / 软件「光魂 Center」）
- 变化：每张卡**自动带最新版本与日期**（如 `最新 v1.6.3 · 2026-09-12`），数据取自下载中心，运营不再手写版本号

### 1.6 留言
- 字段：**保持现有 5 项**（称呼 / 联系方式 / 产品型号 / 咨询主题 / 问题描述），不增减
- 新增：**轻量分流**——顶部先选「售前咨询 / 售后报修 / 商务合作」，下面「咨询主题」选项跟着变；后台按类型自动分派
- 版式：**保持左右两栏**（左文案 + 右表单）

### 1.7 信任条
- 位置：**页脚上面**
- 形式（方案 A）：**分隔线横排**——四项均分，项间竖分割线，上下细线收边，无卡片底
- 图标：每项配 **22px 线性图标**（1.5px 描边、圆头圆角、中性色不发光）；「三年质保」「官方正品」「顺丰包邮」用现有图标库，「实测实验室」**单独画一个**（烧瓶/量杯）
- 内容：保持 4 项（小雪人评测实验室 / 三年质保 / 官方正品 / 顺丰包邮）

### 1.8 服务承诺
- **后台停用**（或删除）；停用后下面模块自动上移，且信任条不再与它重复

### 1.9 页脚
| 项 | 确定内容 |
|---|---|
| 代码动画底 | **保留** |
| 整体结构 | 向参考站靠：品牌大字 + 社交图标 + 大行链接（行间细线）+ 底部公司信息 / 备案号 / 隐私·协议 |
| 备案号 | **底部显示**（可点击跳备案信息页） |
| 社交图标 | **桌面悬停 / 手机点击**弹出浮层：有二维码 → 二维码 + 名称；无二维码 → **账号 + 一句提示**（如 `微信：guanghun-official · 打开微信搜索关注`）；只有链接 → 直接跳转不弹层 |
| 原有二维码区 | **撤掉**，并进图标浮层 |
| 后台数据 | 社交由「图标+链接」+「二维码」两条列表，**合并为每个平台一条**（二维码 / 账号 / 链接三项选填） |

## 3. 素材与上传能力（第 3-1 页衍生，新增）

### 3.1 现状
- **可上传**：图片（png / jpg / jpeg / webp / gif / svg）、视频（mp4 / webm / mov）、**PDF**
- **不可上传**（会被拒 415）：文本、Word / Excel / PPT、压缩包
- 上传大小上限：**统一 50MB**（`UPLOAD_MAX_SIZE` 可配）
- 分类逻辑里**已预留** word / sheet / presentation / zip 的归类，只是白名单没开 → 扩展成本很小

### 3.2 2.0 决定

| 项 | 决定 |
|---|---|
| 格式扩展 | 加**文本**（txt / md / csv）+ **Office 文档**（doc / docx / xls / xlsx / ppt / pptx）+ **压缩包**（zip） |
| 压缩格式再放宽 | 再加 **rar / 7z** |
| 大小限额 | **按类型分档**：图片 10MB / 文档 50MB / 视频 200MB |
| SVG 安全加固 | 上传的 SVG **强制走下载**（不直开）或做标签白名单清洗，防 XSS |
| 删素材前提示 | 删除前提示「被 N 处引用」，避免删掉线上正在用的图 |
| 大文件 | 素材支持**填外链地址**（不上传到服务器），为后续接对象存储 / CDN 铺路 |

> 次要项（暂不列入，需要时再加）：素材库按类型 / 文件名检索；音频格式（mp3 / wav）。
