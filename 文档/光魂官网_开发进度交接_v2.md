**核验方法（重要，供下轮复用）**

**本轮修正的既有问题（非本次改动引入）**
1. `.grid-3` 在 ≥1400 容器会排出 **5 列**（`auto-fit + minmax(240px,1fr)`），6 张卡变「5 + 1」→ 固定 3 列，并新增 2 列 / 1 列断点。
2. 天梯榜行在 390 下超宽 36px，且容器 `overflow:hidden` 不可滚，分数 / 涨跌 / 箭头被裁 → ≤560 收掉缩略图并收窄两列。

4. 后台 ≤1023 单列 `1fr` 被表格 `min-width:720px` 撑开 → 整页横向溢出。
5. 面包屑层级项被 flex 压缩，中文逐字断行成竖排 → 不折行 + 末项省略号。
6. 英文 seed 的历史字段（`title` 写成字符串、`stats` 用 `{k,v}`）导致英文站**静默丢首屏标题与规格行** → 在 `blockUtils` 增加 `asTextLines` 并让 `asStatItems` 兼容 `{k,v}`。
