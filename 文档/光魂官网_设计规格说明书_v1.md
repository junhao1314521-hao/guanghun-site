## 二、视觉方向：苹果骨架 + 电竞皮肤

### 2.1 核心合成规则（唯一需要记住的一条）

> **苹果风是"全局骨架"，电竞感是"局部皮肤"。**

两者不是混在一起，而是**分层管辖**：

| 层 | 管辖范围 | 风格 |
|---|---|---|
| **骨架层**（全局） | 排版、留白、导航、卡片、表单、表格、后台全部 | **苹果风纪律** |
| **皮肤层**（局部） | 首屏海报、产品展示区、天梯榜单区、暗色模式的强调态 | **电竞感** |

### 2.2 允许与禁止

| 电竞感**可以**出现 | 电竞感**禁止**出现 |
|---|---|
| 产品展示大图（深底、边缘光） | 排版与字号（必须克制） |
| 天梯榜单条形（品牌色→青色渐变） | 导航与页脚 |
| 首屏海报动态效果 | 表单与输入控件 |
| 暗色模式的发光描边、`--shadow-glow-accent` | 后台任意位置 |
| 数据数值的等宽字体 + 大字号 | 文案语气（保持中性专业） |

**判定方法**：任何一处新增视觉，先问"它在骨架层还是皮肤层"。**皮肤层的样式不得被骨架层复用**，反之亦然。

### 2.3 两个模式的性格差异

| 模式 | 承载的风格 | 说明 |
|---|---|---|
| **浅色** | 苹果风为主 | 大量留白、细边框、弱阴影、大字号。电竞感仅在产品区局部出现 |
| **暗色** | 电竞感更容易释放 | 深底承担产品的"展台"效果，`--shadow-glow-accent` 可启用 |

这也是把双模式定为"同等重要"的实际收益：**两个模式各有性格，不是一个的倒影**。

## 三、字体

### 3.1 调研结论（当前主流科技站实际用法）

| 站点 / 产品 | 字体 | 可否商用 |
|---|---|---|
| Vercel | **Geist**（自有，Swiss 设计取向） | ✅ SIL OFL 1.1 |
| Linear / Framer / Raycast / Figma / Notion | **Inter** | ✅ SIL OFL 1.1 |
| Stripe | sohne-var（向 Klim 授权） | ❌ 专有 |
| Apple | SF Pro | ❌ 仅限苹果平台，**不可商用** |

**结论**：主流"高级科技感"的字体选择高度集中在 **Inter** 与 **Geist** 两个开源字体上；真正专有的（Stripe sohne、Apple SF）反而不可用。

### 3.2 光魂的字体方案

| 用途 | 字体 | 许可 | 理由 |
|---|---|---|---|
| 拉丁 / 数字 | **Geist** | SIL OFL 1.1 | Vercel 同源，Swiss 极简取向，与"苹果风"高度契合，且比 Inter 更有辨识度 |
| 中文 | **MiSans** | 免费全球商用 | 字形骨架现代、留白匀称，与 Geist 的气质最接近 |
| 等宽（后台数据 / 型号编号） | **Geist Mono** | SIL OFL 1.1 | 与正文字体同族，型号、序号、榜单数值显示更整齐 |
| 降级备选 | Inter + OPPO Sans / 思源黑体 | 均免费商用 | MiSans 缺字或授权有异议时替换 |

**字体栈**（已写入令牌）：

```
--gh-font-sans: "Geist", "MiSans", "PingFang SC", "HarmonyOS Sans SC",
                "Noto Sans SC", system-ui, -apple-system, sans-serif;
```

拉丁字体在前、中文字体在后是标准做法——拉丁字符走 Geist，中文字符自动落到 MiSans。

**合规提醒**：`-apple-system` 与 `"PingFang SC"` 仅作为**本机降级**使用（用户设备自带，不构成分发），**禁止**把 SF Pro / PingFang 字体文件打包进项目。

## 四、设计令牌

### 4.1 三层结构（禁止跨层引用）

```
① 原子层  --gh-blue-500 = #2040ED        裸值，禁止组件直接使用
② 语义层  --color-accent                  按用途命名，组件只能引用这层
③ 使用层  button { background: var(--color-accent) }
```

**硬规则**：

- 组件中**禁止**出现任何十六进制色值、裸 px 字号
- 语义层**禁止**引用另一个语义令牌（只能引用原子层）
- 令牌只能有一份真源（`tokens.css` / `tokens.json` 同源产出），禁止在多处各维护一套

### 4.2 令牌一览

| 类别 | 令牌前缀 | 数量 |
|---|---|---|
| 色彩 | `--gh-blue-*` `--gh-neutral-*` `--gh-cyan-*` | 24 |
| 语义色 | `--color-*`（bg / text / border / accent / status / data） | 40 × 2 主题 |
| 字体 | `--gh-font-*` | 2 |
| 字号 / 行高 | `--gh-font-size-*` `--gh-line-height-*` | 9 组 |
| 间距 | `--gh-space-1` ~ `--gh-space-10` | 10 |
| 圆角 | `--gh-radius-*` | 6 |
| 阴影 | `--shadow-*` | 5 × 2 主题 |
| 动效 | `--gh-duration-*` `--gh-ease-*` | 6 |
| 层级 | `--gh-z-*` | 6 |
| 断点 | `--gh-bp-*` | 4 |

## 五、色彩策略

### 5.1 品牌色的用法边界（重要）

`#2040ED` 是饱和蓝紫，**只允许出现在以下位置**：

| 允许 | 禁止 |
|---|---|
| 主按钮、链接文字、选中态 | 大面积背景色块 |
| 聚焦环、图标强调 | 导航栏底色 |
| 榜单数据条形 | 整页主题色 |
| 悬停/激活的强调描边 | 卡片底色铺满 |

**量化标准**：任一屏内品牌色的**面积占比应低于 10%**。超过即视为滥用。

### 5.2 双主题的取值差异（已解决的对比度问题）

| 语义 | 浅色 | 暗色 | 说明 |
|---|---|---|---|
| 强调色 | `#2040ED` | **`#5B75F5`** | 原色对暗底仅 2.6:1，**必须提亮** |
| 页面底 | `#FFFFFF` | `#0E0E10` | |
| 卡片底 | `#FFFFFF` | `#17171A` | 暗色靠"底更深+卡片稍浅"建立层次 |
| 主文字 | `#17171A` | `#FAFAFB` | |
| 边框 | `#E8E8EC` | `#3A3A42` | |
| 层次手段 | 阴影 | **边框 + 微光** | 暗色下阴影几乎不可见 |

**已验证的对比度**：

| 组合 | 比值 | 结论 |
|---|---|---|
| 品牌色 / 白底 | 6.9:1 | ✅ AA |
| 品牌色 / 暗底 | 2.6:1 | ❌ 改由 `#5B75F5` 承担（4.5:1） |
| 主文字 / 页面底（双主题） | ≥ 15:1 | ✅ AAA |

### 5.3 状态色

四类状态（成功 / 警告 / 危险 / 信息）各含三个令牌：`-color`、`-bg`、`-border`。暗色模式下 `-bg` 与 `-border` 改用**半透明叠加**，确保在任何卡片底色上都成立。

## 六、排版

### 6.1 字号阶梯（苹果风偏大，标题与正文拉距）

| 名称 | 字号 / 行高 | 用途 |
|---|---|---|
| display | 56 / 64 | 首屏海报主标题 |
| h1 | 40 / 48 | 页面主标题 |
| h2 | 32 / 40 | 区块标题 |
| h3 | 24 / 32 | 卡片组标题 |
| h4 | 20 / 28 | 小标题 |
| body-lg | 17 / 28 | 导语、产品描述 |
| body | 15 / 24 | 正文（默认） |
| body-sm | 13 / 20 | 辅助信息、表格 |
| caption | 12 / 18 | 标签、时间、注释 |

### 6.2 排版规则

- **标题字重**：h1/h2 用 600，h3/h4 用 600，display 用 700
- **正文最大宽度**：`≤ 72 字符`（中文 ≤ 40 字）。超宽影响可读性
- **段落间距**：`--gh-space-4`（16px）
- **大标题负字距**：display / h1 使用 `letter-spacing: -0.02em`（苹果风特征）
- **数字用等宽**：价格、型号、数值、榜单数据一律用 `--gh-font-mono`，避免跳动
- **禁止**：全大写中文、超大字号正文、居中的长段落

## 七、间距、圆角、阴影、动效

| 类别 | 规则 |
|---|---|
| **间距** | 8pt 网格。可用值仅 `4/8/12/16/24/32/48/64/96/128`，**禁止任意值** |
| **区块间距** | 桌面 `--gh-space-8`（64），移动 `--gh-space-7`（48） |
| **圆角** | 按钮/输入 `md`(8) ｜ 卡片 `lg`(12) ｜ 弹窗 `xl`(16) ｜ 海报 `2xl`(24) ｜ 标签胶囊 `full` |
| **阴影** | 浅色用 `--shadow-sm/md/lg`；暗色改用 `--color-border-default` + 必要时 `--shadow-glow-accent` |
| **动效时长** | 微交互 `fast`(150ms) ｜ 常规 `base`(200ms) ｜ 页面级 `slow`(300ms) |
| **缓动** | 骨架层用 `--gh-ease-standard`（克制）；皮肤层（产品/榜单）用 `--gh-ease-accent`（爽快） |
| **禁止** | 超过 400ms 的交互动效；弹跳/回弹类缓动；无视 `prefers-reduced-motion` |

## 八、断点与栅格

### 8.1 断点（对应评估报告 A-3，此项此前缺失，现锁定）

| 名称 | 范围 | 栅格 | 边距 | 典型设备 |
|---|---|---|---|---|
| xs | < 640px | 4 列 | 16px | 手机 |
| sm | 640–767px | 6 列 | 24px | 手机横 / 小平板 |
| md | 768–1023px | 8 列 | 32px | 平板 |
| lg | 1024–1439px | 12 列 | 40px | 桌面小 |
| xl | ≥ 1440px | 12 列（最大 1440 居中） | 40px | 桌面大 |

- 栅格间距（gutter）：xs/sm 用 16px，md 及以上用 24px
- 容器最大宽度：`1440px`，超出后居中留白，不拉伸

### 8.2 响应式策略

**桌面优先 + 向下降级**（非移动优先）。理由：官网的产品展示与天梯榜在桌面才是完整体验，移动端是"保留主路径"。

| 断点 | 策略 |
|---|---|
| xl → lg | 保持 12 列，缩小侧边距与区块间距 |
| lg → md | 导航折叠为汉堡菜单；多列卡片降为 2 列；对比表改横向滚动 |
| md → xs | 全部单列；天梯榜保留型号 + 条形 + 数值（对应 PRD REQ-05）；筛选改为抽屉 |

**禁止**：在移动端把天梯榜压成不可读的宽表（PRD REQ-05 明确禁止）。

## 十一、后台 UI 规格

PRD 只给了栏目表，未给 UI 形态。以下为补充（对应评估报告 A-4）。

### 11.1 后台壳

```
┌──────────┬────────────────────────────────────┐
│          │  顶栏：面包屑 · 语言 · 账号          │
│  侧边    ├────────────────────────────────────┤
│  导航    │                                    │
│          │  页面容器（内边距 24 / 最大宽 1600） │
│  (240px) │                                    │
└──────────┴────────────────────────────────────┘
```

- 侧边导航宽 `240px`，窄屏（< 1280px）折叠为 `64px` 图标模式
- 后台**不使用**电竞感任何元素，也不使用大圆角与大留白
- 后台密度高于前台：表格行高 `44px`，字号用 `body-sm`(13px)

### 11.2 四类标准页面形态

| 形态 | 结构 | 适用 |
|---|---|---|
| **列表页** | 页头（标题+主操作）→ 筛选区 → 表格 → 分页 | 产品、文章、资源、咨询、客户列表 |
| **表单页** | 页头 → 分组表单（含必填标记、字段级校验提示）→ 底部固定操作条 | 产品编辑、文章编辑、资源编辑 |
| **详情页** | 页头（标题+状态+操作）→ 描述项 → 关联区块 | 咨询详情、客户详情 |
| **编辑器页** | 顶栏（撤销重做/设备预览/发布）→ 左组件树 · 中预览 · 右属性面板 | 页面装修（PRD REQ-13） |

### 11.3 后台必备状态（PRD REQ-21 已要求，此处落到 UI）

- 空状态：区分"**未配置**"与"**无结果**"，两者文案与视觉必须不同
- 表格加载：骨架行，非全屏转圈
- 批量操作：需显示已选数量与影响范围
- 危险操作：二次确认，且明确写出影响（如"将影响 N 个页面"）

## 十三、无障碍基线

对应 PRD NFR-08。目标级别：**WCAG 2.1 AA**。

| 项 | 要求 |
|---|---|
| 文字对比度 | 正文 ≥ 4.5:1；大字（≥ 24px 或 ≥ 19px 粗体）≥ 3:1 |
| 非文字对比度 | 图标、边框、聚焦环 ≥ 3:1（**这是暗色模式必须提亮品牌色的原因**） |
| 焦点可见 | 禁止全局 `outline: none`；统一用 `--focus-ring` |
| 键盘可达 | 所有交互元素可 Tab 到达，顺序符合视觉顺序；弹窗内焦点锁定 |
| 语义标签 | 表单控件必须有 `label`；图标按钮必须有可读名称（PRD 第 3 章已要求） |
| 状态提示 | **不得仅靠颜色**传递状态（如错误必须同时有图标或文字） |
| 动效 | 尊重 `prefers-reduced-motion`（已写入令牌全局基线） |
| 触控目标 | ≥ 44×44px |

## 十六、交互模式规范（页面稿 v1 已实现）

> 本章是**跨页面复用的交互约定**，实现见 `光魂官网_关键页面稿_v1.html` 脚本区。新增同类交互必须沿用同一参数与降级策略。

### 16.1 横向滑动轨道 `.h-scroll`

两种驱动方式，二选一，按内容密度选择：

| 变体 | 一排可见 | 驱动方式 | 卡位对齐 | 适用 |
|---|---|---|---|---|
| 默认 `.h-scroll` | 多张（约 4） | 箭头翻页 + 指针拖拽 | CSS `scroll-snap` | 竖版海报（`.vcard`） |
| `.h-scroll--duo`（带 `data-hscroll-auto`） | **2 张** | **指针接近方向驱动** | 关闭 snap，由脚本按卡位对齐 | 「按场景选择」等宽版卡 |

**指针接近驱动规则（`--duo` 专属）**：

- 指针在轨道**右半侧 → 向右推进**（后续卡片进入视野）；**左半侧 → 向左回退**；越靠边速度越快
- 中心**死区 16%**：轻微移动不触发
- 速度映射：横向偏移归一化后按 `pow(s, 1.6)` 放大，最大 `13px/帧`；逐帧阻尼 `0.12` 逼近目标，起步与收尾不生硬
- **指针离开 → 平滑对齐到最近一张卡**（按「卡宽 + 间距」取整）
- **仅在精确指针设备触发**：按 `pointerType` 判定，`touch` / `pen` 直接忽略——**不依赖 `(hover:hover)` 媒体查询**（该查询在部分桌面环境并不可靠）
- 命中 `prefers-reduced-motion` 时不启用

### 16.2 滚动驱动生长（天梯榜条形）

- 由 `IntersectionObserver` 在**整组进入视口**时触发，各行按 `90ms` 错峰生长；**非**页面加载即长满
- 不使用 `animation-timeline: view()`（跨浏览器一致性不足），仅作备选
- 无 `IntersectionObserver` 或命中 `prefers-reduced-motion` → 直接呈现终态

### 16.3 底部渐变虚化（首页天梯榜 teaser）

- 用 `mask-image: linear-gradient(...)` 令 teaser 底部虚化收束，**不展示完整榜单**；完整内容在进入榜单页后呈现
- 虚化只作用于展示，不遮挡交互（仍可点击进入完整榜单）

### 16.4 指针物理（磁吸 / 3D 倾斜 / 聚光跟随）

- 统一由**弹簧物理引擎**（单标量阻尼趋近目标 + 统一 ticker）驱动，避免多处各写一套
- 磁吸按钮只做 `translate`（独立属性），**不与 `:active` 的 `scale` 冲突**
- 3D 倾斜用 `.is-tilt` + `--tilt-x / --tilt-y`；进场动画结束后释放 `transform` 占用，把控制权交还倾斜 / 磁吸
- 产品列表卡片做「抬升 + 指针跟随聚光」（不倾斜）；详情页大图可倾斜
- 全部在 `prefers-reduced-motion` 下停用

### 16.5 移动端导航

- 抽屉手风琴内容由桌面端下拉菜单**克隆生成**（运行时清空静态占位，避免重复渲染），保证导航**单一真源**
- 语言入口同步镜像进抽屉，两处共用同一状态
- 汉堡按钮 `aria-expanded` 同步；`Esc` 与点击遮罩关闭
