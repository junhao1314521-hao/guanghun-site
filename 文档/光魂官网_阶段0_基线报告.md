## 二、结构盘点（关键结论）

**页面壳已经统一**：除 3 个自建页外，其余页面都是 `<PageView pageKey>` 薄壳（5–13 行），内容来自数据库中的区块序列。因此"页面风格不统一"不是页面组件各写一套造成的，而是**首屏形态、区块能力、每页配置**三者不一致。

| `/` 首页 | PageView `home` | 21 | carousel + 3 个 hero |
| `/products` | PageView `products` | — | 无页头，直接标题 + 筛选 + 网格 |
| `/products/:id` | 自建 V8 | — | 决策台（B 批已验收） |

## 三、重复实现清单

### 1）咨询 / 留言：3 套形态

| 实现 | 使用位置 | 特征 |
|---|---|---|
| `blocks/InquiryForm.tsx` | `/inquiry`、`ContactBlock` 内嵌 | 完整表单，售前/售后/商务分流，主题联动 |
| `blocks/InquiryDockBlock.tsx` | 首页 `inquiryDock` 区块 | 轻量提问卡，自有 `inq-dock` 类与提交逻辑 |
| `ContactBlock` 引导卡 | `/contact`、`/support`、`/business` | 无表单时输出 CTA 卡（蓝色浅底条） |
| 产品详情 V8 | `/products/:id` | 只有跳转 `/inquiry` 的按钮，无内嵌表单 |

结论：字段与校验没有统一契约；`InquiryForm` 与 `InquiryDockBlock` 各自维护提交与错误态。

### 2）首屏：4 套形态

| 形态 | 使用位置 | 限制 |
|---|---|---|
| `blk-hero` / carousel | 首页 | 支持海报 + 文案 + 按钮 |
| `fullscreenVisual` | 商业合作、下载中心 | **纯媒体，无文案层**（`types.ts` 明确"无文案层"） |
| `supportHero` | 支持中心 | 独立搜索/热词/登录引导语言 |
| 无首屏 | 案例、场景、网点、新闻、联系、产品列表 | 直接进入内容 |

### 3）其它

- 页面壳无重复（已统一 PageView），无需重建。
- 按钮/表单/标签使用 `components.css` 的 `.btn` / `.field` 体系，未发现同类多套实现。
