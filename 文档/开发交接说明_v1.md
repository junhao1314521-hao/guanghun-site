## 一、这次要做什么

把设计层产物落地为**可运行的官网前端**（前台 + 客户中心；后台本轮不开发，仅有文字规格）。

## 三、必须遵守的硬约束（违反即返工）

1. **令牌单一真源**：所有颜色 / 字号 / 间距 / 圆角 / 阴影 / 动效一律引用语义令牌；禁止裸色值、裸 px 字号、任意间距值。
2. **双主题等价**：每个组件、每个页面都要在浅色 + 暗色两套下验证；暗色不是浅色的倒影（强调色暗色下用 `#5B75F5` 提亮）。
3. **电竞感隔离**：仅允许出现在「产品展示区」与「榜单区」；导航、页脚、表单、后台一律不得出现。皮肤层样式不得被骨架层复用，反之亦然。
4. **可访问性 WCAG 2.1 AA**：正文对比度 ≥ 4.5:1；焦点可见（统一 `--focus-ring`）；触控目标 ≥ 44×44px；表单必须有 `label`；图标按钮必须有可读名称；状态不得只靠颜色。
5. **字体商用合规**：Geist / MiSans / Geist Mono 均免费商用；**禁止**打包 SF Pro / PingFang 字体文件。
6. **断点固定**：`xs <640` / `sm 640–767` / `md 768–1023` / `lg 1024–1439` / `xl ≥1440`；桌面优先、向下降级；容器最大 1440 居中。
7. **动效**：微交互 150ms / 常规 200ms / 页面级 300ms；禁止 > 400ms、禁止弹跳缓动；必须尊重 `prefers-reduced-motion`。
8. **状态完整**：交互组件 7 态（默认/悬停/聚焦/激活/禁用/加载/错误）；数据区域 5 态（加载中/空/正常/超长/错误）。
9. **术语统一**：咨询（非工单/留言）、资料（非资源）、天梯榜、型号、体验点、Center、语言。

## 五、首轮开发范围与顺序

**页面（10 个，与页面稿一一对应）**：首页、产品列表、产品详情、天梯榜、Center 软件、服务支持、商业合作、关于光魂、客户中心、全站搜索。

**建议顺序**：

1. 搭工程骨架，原样引入 `tokens.css` + `components.css`；实现**主题切换**（浅色/暗色，默认跟随系统）。
2. 通用布局：顶栏（含语言入口下拉）、产品大菜单、页脚、移动端抽屉（内容由下拉菜单克隆生成，单一真源）。
3. 逐页还原：**先做首页跑通全链路**（结构 → 令牌 → 组件 → 响应式 → 双主题 → 状态 → 验收），再铺其余页面。
4. 补齐双主题、四档响应式、无障碍、各组件状态。
5. 逐条过验收。

## 六、关键交互（还原时不要丢）

| 交互 | 规格 |
|---|---|
| 首页「按场景选择」横向轨道 | 一排 **2 张**；指针在**右半侧→向右推进**、左半侧→向左回退；中心死区 **16%**；离开后**对齐到卡位**；**仅精确指针设备**触发（按 `pointerType` 判定，触屏/手写笔忽略，不依赖 `(hover:hover)`） |
| 天梯榜条形 | 滚动**进入视口才生长**（`IntersectionObserver`），各行 **90ms 错峰**；非加载即长满 |
| 首页天梯榜 teaser | 底部**渐变虚化**（`mask-image`），**不展示完整榜单**，点入榜单页看全 |
| 指针物理 | 磁吸 / 3D 倾斜 / 聚光跟随统一由弹簧引擎驱动；`prefers-reduced-motion` 下停用 |
| 顶栏语言入口 | 图标 + 下拉（简体中文 / 繁體中文 / English）；移动端抽屉镜像同一份选项 |

## 七、验收标准

- 以 `光魂官网_PRD可测AC核对表_v1.0.md` 的**可测 AC** 逐条核对（是否有独立地址、边界值是否精确、越权是否被拒绝）。
- 每个页面交付：**双主题截图**、**5 种数据状态**、**响应式 390 / 768 / 1280 / 1440**。
- 控制台 **0 error**；无文档级横向溢出（`documentElement.scrollWidth ≤ innerWidth`）。
- 组件按 7 态 / 5 态出图，缺一不算完成。
