### R-04 账号体系 / 找回密码 —— A 类（需选通道）

**现状证据**

- 注册、登录、会话、退出、错误提示均可用；密码错误返回 401 与中文提示。
- 找回密码接口 `POST /api/auth/forgot` 存在，会生成一次性重置令牌。
- **生产环境不返回令牌、也没有邮件/短信通道**：用户点“找回密码”后收不到任何东西，等于不可用。

**缺口**：缺发送通道。**二选一**：

| 方案 | 需要你提供 | 特点 |
|---|---|---|
| 企业邮箱 SMTP | 发件邮箱、SMTP 地址、端口、授权码 | 成本低，可能进垃圾箱 |
| 短信服务 | 阿里云/腾讯云短信签名与模板 | 到达率高，按条计费 |

**我拿到后的动作**：接入通道 → 令牌邮件/短信 → 重置页 → 全流程实测（含过期令牌）。

### R-05 素材上传基础 —— 部分达标

**现状证据**

- 图片 10MB / 文档 50MB / 视频 200MB 分档限制，可按环境变量覆盖。
- 超出限额返回中文原因；支持素材库多选、排序、替换。
- 图片上传会生成尺寸变体（srcset）。
- **安装包（exe / dmg / msi）不在素材库白名单**，后台字段提示“请填对象存储 / CDN 外链”。

**缺口 / 待改**

1. 安装包无法直传，Center 安装包必须依赖外部 CDN（与 R-02 联动）。
2. 上传失败原因已可读，但缺少“批量上传进度”汇总。
3. 大文件（>50MB 文档）无断点续传。

**建议**：R-02 定下 CDN 后，统一走外链 + 校验值；是否支持直传大安装包再评估。

### R-06 发布链路 —— B 类（可直接开发）

**现状证据**

- 后台“保存”= 直接写 `content_pages`，**前台立即可见**；没有草稿隔离。
- “发布”生成的是**版本快照**（用于回滚），不是“上线开关”。
- 定时发布（schema v7 `publish_schedules`）：到点把创建时捕获的快照写入线上，支持取消与失败留痕。
- 页面有 `enabled` 上下线（下线后前台显示“已下线”，导航/页脚链接被级联过滤）。

**缺口**

1. 编辑中的内容会立刻影响线上，无法“先改好、再发布”。
2. 定时发布是“到点应用快照”，但编辑期间线上已经变了，语义容易误解。
3. 没有“预览未发布版本”的入口。

**建议改法（不改变现有数据结构的前提下）**

- 保存 → 写草稿表 / 草稿字段；线上继续读已发布版本。
- 发布 → 草稿覆盖线上 + 生成快照；定时发布 → 预发布草稿，到点切换。
- 预览 → 带 token 的预览链接，只读草稿，不索引。

**工作量提示**：涉及数据库迁移（新增草稿字段/表）与后台发布交互，建议单独一个批次做，不与前台混改。

### R-07 前后台字段一致性 —— B 类（已抽查，待端到端）

**现状证据（代码级抽查）**

- 产品 13 个关键字段在前台均有消费点：`warranty / inBox / weight / os / features / attributes / skuOptions / skus / buyUrl / gallery / priceValue / releasedAt / flag`。
- 体验点：封面、相册、电话、营业时间已在后台可改，前台已验证生效（缺失有明确占位）。
- 页面/区块：后台字段目录 `blockCatalog.ts` 与渲染层 `blocks/*` 一一对应，未知字段会被忽略而不是报错。

**缺口**：还没做“后台改一条 → 前台看结果”的逐字段端到端核对（尤其是：产品 SKU、下载校验值、文章封面、案例数据、站点公告定时）。

**建议做法**：选 5 个高频资源（产品 / 体验点 / 下载 / 文章 / 站点配置），每类改 1 条真数据，前台逐项截图对比，输出差异清单再修。

### R-08 安全 —— C 类（已达标，注意 HTTP 阶段限制）

- 后台口令非默认值；未授权接口返回 401/403。
- 上传有类型与大小限制；接口无默认口令暴露。
- **当前限制**：测试服走 HTTP，`COOKIE_SECURE=0`、`TRUST_PROXY=0`；切域名 + HTTPS 后需改为 `1/1`。
- 浏览器地理定位在 HTTP 下不可用（已在体验点页做降级提示，非安全缺陷）。

---

### R-09 运维 —— C 类（已达标）

- systemd `website` 开机自启、异常重启；`install.sh` 可重复执行并自动备份旧代码（保留最近 3 份）。
- 数据持久化：`/opt/website/data/gh.sqlite`，上传与备份同目录。
- 日志 `logrotate` 每日轮转、保留 14 天；`/healthz` 健康检查每次部署校验。

## 五、验收方式（每项都要有证据）

- R-02：每条下载点击后 HTTP 200、文件大小与后台记录一致、类型正确。
- R-03：8 款产品逐款点主按钮，落到正确商城或咨询页，无 `example` 占位域。
- R-04：新账号走完“申请 → 收信/短信 → 改密 → 新密码登录”，过期令牌被拒绝。
- R-06：保存草稿后前台不变；发布后前台更新；定时到点自动切换；可回滚。
- R-07：后台改 1 条 → 前台截图对比，字段逐项一致。
