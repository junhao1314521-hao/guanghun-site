# 光魂官网 · Phase 0 盘点与问题清单（2026-11-04）

> 盘点对象：正式环境 `http://8.163.108.144:3002`（前台 + 后台）
> 方法：真实 HTTP 请求、浏览器逐页巡检、接口实测、代码核对、桌面 1280 宽度；690 窄屏此前已验证，手机 320/390/430 设备矩阵待 Phase 2 补测。
> 结论：**框架与后台能力比预期完整，但“数据真实性”和“上线阻塞项”较多，当前不适合直接上架产品。**

## P1 · 体验、一致性与 SEO

| ID | 问题 | 证据 | 影响 | 阶段 |
|---|---|---|---|---|
| P1-1 | 详情页无效 ID 显示空白 200 | `/products/not-exist`、`/downloads/not-exist`、`/faq/not-exist`、`/articles/not-exist`、`/business/cases/not-exist`、`/business/venues/not-exist` 均无 h1、无内容、无 404 | 软 404，SEO 与用户都受损 | Phase 1 |
| P1-2 | 缺失静态资源返回 200 HTML | `/uploads/nope.zip`、`/media/nope.jpg`、`/assets/nope.js` 均 `200 text/html 2313B` | 掩盖资源缺失；下载失败无法被监控发现 | Phase 1 |
| P1-3 | canonical / OG / JSON-LD 使用占位域名 | 所有页面 canonical 为 `https://www.guanghun.example/...` | 搜索引擎可能不收录正确页面 | Phase 5 |
| P1-4 | 原始 HTML 标题/描述对所有路由相同 | 直接请求 `/`、`/products`、`/downloads`、`/center` 均返回 `<title>光魂 · 电竞外设官网</title>` 与默认描述；JS 执行后才更新 | 社交分享、部分爬虫看到错误信息 | Phase 5 |
| P1-5 | meta description 使用后台内部描述 | `/products` 描述为“产品列表装修 + 数据源区块。”；`/downloads` 为“下载中心装修 + 数据源区块。” | SEO 文案泄漏内部术语 | Phase 5 |
| P1-6 | 现有页面缺 SEO 描述编辑入口 | 页面装修器无 `seoTitle/seoDescription` 字段；仅“新建页面”弹窗有 | 运营无法修正上面两条 | Phase 4/5 |
| P1-7 | 首页 H1 是“首页”，文章列表/体验点详情 H1 为空 | 浏览器 DOM 实测 | 语义与 SEO 结构不完整 | Phase 5 |
| P1-8 | 富文本编辑器缺少表格与图片上传 | 工具栏仅支持链接、图片地址、基础格式；无表格、无素材库选图、无粘贴图片 | 长文/评测排版效率低 | Phase 4 |
| P1-9 | 后台 43 个栏目、6 个分组，命名有歧义 | “分类与参数”“组件库/模板/样式”“体验点管理”在商业合作下、“服务评价/服务信息”分家 | 运营找不到功能 | Phase 4 |
| P1-10 | 找回密码在生产环境是死路 | 代码只在非生产返回 `devToken`，生产无邮件服务 | 用户忘记密码无法自助恢复 | Phase 1 |
| P1-11 | 首页过长、重点产品区过密 | 首页高度 6710px；连续 5 个 21:9 产品大块（约 2710px） | 浏览疲劳，重点不突出 | Phase 2 |
| P1-12 | CTA 文案不统一 | 全部产品卡为“进一步了解”，首页部分卡片同时有“进一步了解”和“购买”；重点产品为“立即购买” | 用户不知道点哪个 | Phase 2 |
| P1-13 | 案例/体验点详情标题泛化 | `/business/cases/:id` 标题为“合作案例 · 光魂”；体验点为“体验点详情 · 光魂” | 分享与搜索表现差 | Phase 5 |
| P1-14 | 后台没有下载文件有效性状态 | 下载列表只显示“外链 / 素材库”，不显示文件是否存在、大小是否匹配 | 无法在后台发现假链接 | Phase 4 |
| P1-15 | 图片上传未压缩、未生成多尺寸 | 上传原图直接落盘（AC-S6 未完成） | 大图拖慢前台，占磁盘 | Phase 5 |
