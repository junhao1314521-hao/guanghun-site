> **用途**：把《[后端接口契约 v1](./光魂官网_后端接口契约_v1.md)》§5 的 **13 项待确认项**收敛成一张可勾选、可签署的卡片，供**后端 / 产品**逐条回填。

## 一、怎么用（3 步）

1. **逐行勾选**：在每行「结论」列二选一（建议默认 / 其他）。
2. **写清口径**：选「其他」的，在「变更影响」列右侧或备注中写明具体口径。
3. **签署回传**：填好第四节的签署栏，回传前端 → 前端据结论对齐 → **冻结契约 v1**。

> 默认值即**前端倾向**，参考后端 `gh-server/` 目前**已按该默认实现**；若某行结论为「其他」，请对照第三节「影响面」确认改动范围。

## 三、影响面速查（若结论 ≠ 建议默认）

> 便于评估改动量：**只影响前端** / **只影响后端** / **前后端同步**。

| # | 结论若变 | 改动方 | 具体改动 |
|---|---|---|---|
| 1 | 改用 `{code,data}` 包装 | 前端 | `src/api/client.ts` 的 `createHttpTransport` 增加解包逻辑（读取 `data` 字段） |
| 2 | 需分页 | 前后端 | 前后端补分页字段（`page/size/total` 或 cursor）；页面加载改为分页/无限滚动 |
| 3 | 需鉴权 | 前后端 | `client.ts` 统一注入 `Authorization` / Cookie；后端加校验中间件 |
| 4 | 未登录返回 401 | 前端 | `useApi` / `AccountPage` 增加「未登录」分支（跳登录或空态） |
| 5 | 空结果语义调整 | 前端 | 非 404 端点错误态分支调整（区分「失败」与「空」） |
| 6 | 前端放宽类型 | 前端 | `gh-web/src/data/*.ts` 移除相关 `as const`，放宽为 `string` / `string[]` |
| 7 | 值保持固定 | — | 保持现状（类型收窄为字面量），无需改动 |
| 8 | 统一键名风格 | 前后端 | 后端改键名 + 前端 `api/*` 与 `data/*` 同步改键名 |
| 9 | 其他日期格式 | 前后端 | 数据层日期文案统一；如涉时区需补完整时间戳 |
| 10 | 需强缓存 / 协商缓存 | 后端 | `app.ts` 增加 `Cache-Control` / `ETag` / `If-None-Match` 处理 |
| 11 | 需 i18n | 前后端 | 后端按 `Accept-Language` 返回多语言；前端引入 i18n 文案层（**当前为阻塞项 M5**） |
| 12 | 前端自持枚举 | 前端 | `variant` / `art` / `icon` 由前端按 id 映射，后端不再下发 |
| 13 | 改为 id 由前端映射 | 前后端 | 后端返回资源 id，前端建立 id → 路由映射表 |
