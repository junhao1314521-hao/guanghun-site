## 2. W1 · 后台基础能力

| 任务 | 内容 | 验收点 |
|---|---|---|
| **T1.1 页面上下线** | `Page` 增加 `enabled`；页面开关**内联在「页面列表」**（不新开栏目） | 关闭后前台该路由不可达；回到列表可一键恢复 |
| **T1.2 下线级联** | 渲染层自动过滤指向已停用页面的链接；后台显示「当前 N 处引用」清单 | 停用页面后，导航 / 页脚 / 区块里的该链接自动消失，无死链 |
| **T1.3 素材库扩展** | 白名单加 `txt/md/csv`、`doc/docx/xls/xlsx/ppt/pptx`、`zip/rar/7z`；**按类型分档**（图片 10MB / 文档 50MB / 视频 200MB）；SVG 强制下载或白名单清洗；**删除前提示引用数**；素材可填**外链地址** | 各类型可上传；超限给出明确提示；删除线上在用素材有二次确认 |
| **T1.4 默认主题** | 站点配置加「默认主题：跟随系统 / 浅色 / 暗色」（挂「样式」栏目）；前台 `initTheme` 消费，**用户手动选择优先** | 后台切换默认主题后，新访客（无本地记录）按该主题渲染 |
| **T1.5 图片自动变体** | 上传时服务端自动生成多宽度 webp 变体；前台 `srcset` 按需加载 | 只传一张原图即可，手机端命中小图；无变体时退化为单张（不报错） |
| **T1.6 后台控件与版式规范** | 开关 / 引用清单面板 / 字段控件 / 抽屉各只保留**一套**，写入验收项 | 新增能力逐一对照通过；后台无「一套控件两个样」 |

### Render 同步说明
- 仓库内**已有** `render.yaml`（Blueprint，Docker 运行）与 `Dockerfile`（前端构建 + Express 同源托管），**可以直接同步部署**。
- 推送 `main` 后 Render 会自动重新构建部署（`autoDeploy: true`）；也可在 Render 手动触发。
- **注意**：免费实例**没有持久盘**，SQLite 库与 `uploads/` 重启会重置（首次访问自动用种子重建）。要保数据需挂 **Persistent Disk** 并设置 `DB_PATH` / `UPLOAD_DIR`（参考 [交付包说明.md](../交付包说明.md)）。
- 首次部署请设 `ADMIN_PASSWORD` / `ADMIN_OPERATOR_PASSWORD`；生产建议同时设 `COOKIE_SECURE=1`、`SITE_ORIGIN`、`TRUST_PROXY=1`。

**实测（沙箱浏览器，视口 613×819 ≈ 手机宽度）**
- 24 条路由全部可达（HTTP 200）；
- 首页默认启用 **10 个区块**（首屏轮播 + 5 张海报 + 产品矩阵 + 固件驱动 + 留言 + 信任条），其余 13 块默认停用；

- **默认主题**：站点设 `dark` 后，无本地记录的访客实际渲染为暗色；
- **素材与性能**：上传 2000×1200 PNG → 服务端自动生成 480/960/1600 webp 变体，前台图片输出 `srcset`；
- **产品相册**：写入 `gallery` 后前台缩略图随数量变化（未配置时回退内置 4 视图），「查看大图」灯箱可开、`Esc` 可关；
- **后台**：7 个关键栏目 0 横向溢出、0 乱码、0 控制台报错；页面列表开关与引用清单、样式栏目默认主题、组件库新块、素材格式白名单、品牌资料栏目均已就位；
- 全站零控制台报错、零乱码、无横向溢出。

**限制与已知项（如实记录）**
1. 沙箱浏览器视口固定为 613×819，**桌面宽屏无法实拍**；桌面路径以「无横向溢出 + 类型 / 构建 / 单测 + DOM 结构核对」覆盖，建议上线前在真实浏览器补一次宽屏走查。
2. 「型号支持」索引页用「卡片网格 + 种子数据」承载（未做数据源区块），故暂无「每页条数」控件。
3. 品牌资料的「留资 / 申请授权」为「明确提示 + 跳 `/inquiry`」，未做独立留资表单。
4. 富文本 / HTML 自由内容区块里运营手填的 `<a>` 不参与下线级联（由白名单净化渲染，非结构化链接）。
