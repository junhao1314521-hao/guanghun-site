# 光魂 Center 页面 · 三套详细方案 v1.0

> 前提：三套方案都满足四条硬约束——① 视觉与交互全部由代码构建，不用静态太空图/视频；② 软件界面按真实 Center 1:1 复刻（已解包验证）；③ 下载入口在首屏、页中、页尾三次可达；④ 版本 / 大小 / 日期 / 支持型号全部取真实值。
> 差别只在**叙事方式**与**首屏气质**。

---

## 方案 A · 深空控制台（Deep Space Console）

**一句话概念**：软件是你在显示器宇宙里的驾驶舱。

### 首屏

- 画面全部代码生成，四层叠加：
  1. Canvas 2D 星场：160 个粒子，远近两层，近层带轻微拖尾，鼠标移动产生 6px 视差；
  2. CSS 渐变地平线：底部一条蓝色弧光，配 60px 高斯模糊，呼吸周期 8s；
  3. SVG 细网格：24px 栅格，径向遮罩只保留中心 60% 可见；
  4. 噪点层：3% 透明度，避免大面积渐变出现色带。
- 文案左侧，右侧是一块**真实可操作的 Center 窗口**（不是截图）：16:10 玻璃面板，内置 6 个导航和状态栏，首屏内就能拖动亮度条。
- 窗口初始 `rotateX(8deg) rotateY(-6deg)`，滚动 200px 内归正；文案逐行 40ms 错峰上浮。
- 底部悬浮下载条：`下载 Windows 版 · v1.3.3 · 4.46 MB`。

### 叙事主线（8 屏）

首屏 → 六模块总览 → 可操作模拟器 → 场景切换 → 功能深读 → 支持设备 → 下载安装 → 更新日志 / FAQ。

### 交互亮点

1. **窗口活体化**：首屏窗口可点导航、可拖滑条，预览画面随之变化。
2. **星场响应**：鼠标移动时近层粒子反向偏移，形成"穿过星尘"的纵深感。
3. **滚动光带**：滚动时地平线辉光沿水平方向缓慢移动，作为整页的情绪线索。
4. **场景联动**：切到"对战"，星场颜色偏冷、辉光加速；"办公"则转为暖白、辉光近乎静止。

### 视觉语言

深空黑 `#05070D → #0A1020`，品牌蓝 `#3B82F6`、青 `#38BDF8`；标题白色 90%，正文 `#A8B0C0`；数字用 Rajdhani，读数用 JetBrains Mono。

### 技术实现

- Canvas：单画布、DPR≤2、`requestAnimationFrame` + 页面隐藏暂停、移动端粒子减半。
- 视差：滚动值写入 CSS 变量，由 transform 消费，避免 React 每帧重渲染。
- 降级：`prefers-reduced-motion` 下星场静止、窗口不旋转、光带不动。

### 优势 / 风险

- 优势：品牌情绪最强，和现有官网气质连续，实现风险最低。
- 风险：科技品牌常见套路，差异化靠"可操作窗口"撑，首屏之外容易回到普通软件页。

## 方案 B · 面板剖面（Inside the Panel）

**一句话概念**：从一块 OLED 的横截面钻进去，软件就在里面。

### 首屏

- 不画宇宙，画**显示器本身**。整屏是一块被放大的面板剖面：
  - 最外层玻璃：一道 15° 斜向高光，缓慢扫过；
  - 偏光层 / 发光层 / 驱动层：三层半透明色带，用 `repeating-linear-gradient` 画出亚像素栅格（RGB 竖条）；
  - 像素格：CSS `background-size: 6px 6px` 的细密点阵，越靠中心越亮。
- 画面中央是一行超大的等宽读数：`27" · 2K · 540Hz · 0.03ms`，像示波器上的标签。
- 鼠标移动时，**一个圆形放大镜跟随光标**，镜内亚像素被放大 8 倍并显示 RGB 三条色带——用 CSS mask + 双层背景实现，不依赖 WebGL。
- 滚动进入时，镜头"推进"：整块面板 `scale(1) → scale(2.4)`，透明度渐隐，Center 窗口从像素之间"浮"出来，接管首屏。

### 叙事主线（9 屏）

面板剖面首屏 → 镜头推进转场 → Center 窗口登场（可操作）→ 六模块 → 一个功能一段"剖面"（调校 / 电竞 / 固件）→ 支持设备 → 下载 → 更新日志 / FAQ。

### 交互亮点

1. **像素放大镜**：光标即镜头，实时看到 RGB 子像素结构。
2. **滚动推进**：sticky 首屏 + `scale` 与 `opacity` 映射滚动进度，形成"钻入屏幕"的连续镜头。
3. **层剥离**：功能深读时，三层剖面可随滚动逐层淡出，露出下一层内容。
4. **参数刻度**：所有控件用刻度尺样式，拖动时数值与刻度同步，强化"专业仪器"感。

### 视觉语言

近黑底 + 玻璃青 `#7DD3FC` + 品红点缀 `#F472B6`（对应 RGB 子像素）；大量 1px 发丝线；字体用 Rajdhani + JetBrains Mono；材质以"玻璃 / 金属 / 发光层"为主，不用星点。

### 技术实现

- 首屏纯 CSS 渐变 + `mask-image` + `transform`，无 Canvas；放大镜用一个 `div` 跟随 pointer，`background-position` 反向偏移。
- 滚动推进用 `position: sticky` + `IntersectionObserver` 计算进度，写入 CSS 变量。
- 移动端取消放大镜与推进，改为静态剖面 + 窗口卡片。

### 优势 / 风险

- 优势：**视觉最独特**，与显示器产品强绑定，一眼记住；"从硬件进入软件"的叙事很顺。
- 风险：制作精度要求高，渐变与栅格稍有偏差就会显脏；滚动推进在低端机上要严格控制层数与模糊。

## 方案 C · 信号矩阵 / 仪表盘（Signal Matrix）

**一句话概念**：Center 是一台显示器的仪表盘，页面本身就是仪表盘。

### 首屏

- 整屏是一块**数据墙**，没有任何插画：
  - 背景：深黑 + 48px 等距网格 + 一圈极细的同心圆刻度；
  - 左侧：三行超大等宽数字 `540 Hz` / `0.03 ms` / `1500 nit`，进入时从 0 滚动到目标值；
  - 中央：一条实时波动的信号波形（Canvas 2D，正弦叠加噪声），代表刷新率与帧同步；
  - 右侧：一块"通道面板"，6 个通道对应 6 个功能模块，鼠标悬停时波形叠加对应频段；
  - 底部：一排**真实可拖的滑条**（亮度 / 对比度 / 色温），拖动时整屏数字与波形同步变化。
- 下载按钮做成"启动"样式：`▶ 启动 Center · Windows`，旁边是版本与大小。

### 叙事主线（8 屏）

数据墙首屏 → 六通道总览（悬停联动波形）→ 完整控制台（6 Tab 可操作）→ 场景预设（一组参数快照）→ 应用联动（进程 → 模式的时间轴）→ 支持设备（矩阵表）→ 下载（校验信息）→ 更新日志 / FAQ。

### 交互亮点

1. **首屏即 Demo**：不用滚到第三屏，首屏就能拖滑条、看读数变化。
2. **波形联动**：拖亮度 → 波形振幅变化；切预设 → 波形频率切换；HDR 开 → 多一层高频纹理。
3. **通道扫描**：鼠标在六通道间移动，有一条扫描线跟随，像示波器的触发游标。
4. **参数快照**：场景卡保存一组"参数指纹"（6 个迷你刻度条），点击即回放到控制台。

### 视觉语言

黑 `#030507` + 品牌蓝 + 荧光青 `#22D3EE`；所有分隔用 1px `rgba(255,255,255,.08)`；标题偏工程感（Rajdhani Condensed），正文克制；几乎没有大圆角，改用 4–8px 小圆角与切角，传递"仪器"而非"消费电子"。

### 技术实现

- 波形用单块 Canvas，60fps，DPR≤2；无交互时降为 30fps 省电。
- 数字滚动用 `requestAnimationFrame` 插值，只播放一次。
- 滑条全部原生 `input[type=range]`，自定义轨道样式，保证键盘与读屏可用。
- 首屏不加载任何图片，首屏 JS 预算可控制在 120KB 内。

### 优势 / 风险

- 优势：**最贴合"软件"本身**，专业感最强，交互最实在；首屏转化路径最短。
- 风险：情绪温度低，偏"极客"，对普通消费者的吸引力弱于 A/B；需要克制的排版功底，否则容易像后台管理界面。

## 三套对比

| 维度 | A 深空控制台 | B 面板剖面 | C 信号矩阵 |
|---|---|---|---|
| 首屏气质 | 宇宙 / 品牌 | 硬件 / 精密 | 数据 / 专业 |
| 记忆点 | 星场 + 悬浮窗口 | 像素放大镜 + 钻入屏幕 | 数据墙 + 实时波形 |
| 差异化 | 中 | **最高** | 高 |
| 情绪温度 | 高 | 中高 | 低 |
| 开发风险 | 低 | 高 | 中 |
| 移动端难度 | 低 | 高 | 中 |
| 与软件的相关性 | 中 | 中高 | **最高** |
| 适合的决策理由 | 稳妥、延续品牌 | 想让人一眼记住 | 想突出专业与可玩性 |

## 推荐

- 如果目标是**稳妥上线且不输气质**：选 A。
- 如果目标是**做一支能传播的页面**：选 B，但要接受更高的制作精度要求。
- 如果目标是**让人相信这软件真的专业、真的好用**：选 C，它把"可操作"放到了第一屏。

我的建议：**C 为主，吸收 B 的"像素放大镜"作为首屏的一个小交互**。这样首屏既是数据仪表盘，又有硬件质感，情绪与专业兼得；A 的星场可以作为页尾 CTA 的背景收尾，不占首屏。
