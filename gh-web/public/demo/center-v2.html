你可能想问

显示器接上后没有识别到，怎么办？

请用 DP 或 USB-C 直连，不要经转接坞；确认显示器处于对应输入源，并在显示器菜单里开启 DDC/CI，然后回到 Center 点一次刷新。

支持哪些操作系统？

Windows 10 / 11 64 位。当前暂不提供 macOS 版本，更早的 Windows 版本不保证可用。

应用联动是怎么工作的？

选择一个 Windows 进程和对应预设后，该程序进入前台时自动切换模式，离开或退出后恢复原模式；也可以只在程序运行时切换。

固件升级中途失败怎么办？

升级过程中请保持显示器连接与供电，避免断电或拔线。若升级异常，重新连接后可在 Center 里再次检查更新；仍无法恢复时请联系售后支持。
