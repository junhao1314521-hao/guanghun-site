安装与使用

显示器接上后 Center 没有识别到，怎么办？

请用 DP 或 USB-C 直连（不要经转接坞），确认显示器处于对应输入源，并在显示器 OSD 菜单里开启 DDC/CI；开启后回到 Center 点一次刷新。

支持哪些操作系统？

Windows 10 / 11 64 位。当前暂不提供 macOS 版本，更早的 Windows 版本不保证可用。

应用联动是怎么工作的？

选择一个 Windows 进程和对应预设模式后，该程序进入前台时 Center 自动切换模式，离开或退出后恢复原模式；也可以选择「运行模式」，只按进程是否运行来切换。

固件升级中途失败，显示器还能用吗？

可以。升级中断不会清空原固件，显示器仍可正常使用；重新连接后 Center 会提示重试，升级过程中请保持连接与供电。
