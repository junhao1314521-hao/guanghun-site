# 光魂 Center 官网改版方案 v3

> 对标：Apple iPhone 18 Pro 产品页
> 目标：把 Center 从「特效堆叠的 demo」改成「有空间感、有克制感的产品页」
> 状态：方案待确认，确认前不动现有页面

---

## 一、需求反述

1. **以我的需求为准**，不是让你自由发挥。
2. **对标 Apple iPhone 18 Pro 产品页**，拆解它的布局、模块分布、文字排版、UX 交互，再结合光魂自己。
3. **不排斥 "Center" 这个英文用渐变**，渐变字可以保留，但只用在它身上。
4. **先出网页方案，不要出 Demo**。现有 Demo 已经像成品，我要先看你怎么做、大概长什么样，确认后再做正式页。
5. **整体要有科技感、高级感、大场景三维感**，不是平面卡片堆叠，也不是夸张翻转。

核心矛盾：上一版把「科技感」做成了星空铺满 + 渐变大标题 + 62° 翻转。你要的是 Apple 那种「产品放在一个有光、有纵深的空间里」，靠空间、光、尺度、留白成立，而不是靠装饰。

### 2.2 布局规律

- **首屏只放三样**：产品、背后巨型金属字、底部两行信息（左下名称+主张，右下价格+购买）。
- **一屏一个主张**。第二屏立刻切成「居中大标题 + 一段 15–17px 说明」，四周全空。
- **媒体占 70%**。功能模块是全屏影像，文字只占 1–2 行，压在图上或紧贴图下。
- **没有卡片网格、没有六宫格、没有图标墙**。功能细节用 2 列横向轮播，不是平铺。
- **规格用双栏**：左边超大数字（48MP、8x），右边 3–5 行参数。
- **购买条常驻**：滚动后顶部出现一条 40px 高的浮动条，只有产品名 + Explore + Buy。

### 2.3 文字排版

| 层级 | 字号 | 用法 |
|---|---|---|
| 首屏主张 | 80–96px | 一句话，紧字距 |
| 模块标题 | 56–72px | 居中或左对齐，1–2 行 |
| 引导小标 | 17–21px | 灰色，如 "Pro camera system" |
| 正文 | 17px | 行高 1.5，每段 2–3 行 |
| 辅助 | 14px | 参数、脚注 |

- 字距收紧（-0.02 ~ -0.04em），行高紧。
- 中文对应：标题 56–64px，正文 17px，行宽 30–34 字。
- **全站没有渐变标题**，唯一的金属质感来自首屏产品图里的 "Pro" 字。

### 2.4 UX 交互

- **滚动即时间轴**：产品固定，文案交叉淡入；颜色随产品变化。
- **动效 0.6–1s，缓动柔和**，没有弹跳。
- **最大的动作是推近和换色**，没有翻转、没有旋转。
- 轮播用左右箭头 + 拖拽，卡片不浮起。
- 购买条在首屏之后才出现，不打断首屏。

### 2.5 「大场景三维感」是怎么来的

Apple 不是用 WebGL 做交互，而是用**渲染好的影像**：浅景深、侧逆光、镜头缓慢推进、产品表面反射。三维感来自四件事：

1. **光有方向**（主光 + 轮廓光 + 地面反射）
2. **有前后层**（产品实、背景虚）
3. **镜头有运动**（推近、轻微横移）
4. **尺度参照**（产品占画面比例、留白大小）

这四点可以直接搬到网页里，不需要真 3D 模型。

## 四、设计规范

### 4.1 栅格与间距

- 容器最大宽 1200px，12 列，列间距 24px，页面左右留白 48px（移动端 20px）。
- 模块上下内边距：桌面 160px，平板 120px，移动 88px。
- 首屏内容底部对齐，距底 64px。

### 4.2 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#050506` | 页面底色 |
| `--surface` | `#0d0e10` | 下载卡、轮播卡 |
| `--line` | `rgba(255,255,255,.10)` | 分隔线 |
| `--text` | `#f5f5f7` | 主文字 |
| `--muted` | `#a1a1a6` | 正文次级 |
| `--dim` | `#6e6e73` | 辅助、脚注 |
| `--cool` | `#9db4ff` | 冷光 |
| `--warm` | `#ffb27a` | 暖轮廓光 |

- 全站只有一个强调色方向：冷光为主、暖光只做轮廓，不出现第三种彩色。
- "Center" 渐变：`linear-gradient(100deg, #ffffff 0%, #c8d3ea 42%, #8f9bb3 68%, #ffd2a8 100%)`，透明度 0.9，仅首屏使用。

### 4.3 字体

- 西文：SF Pro Display / Inter；中文：PingFang SC / 思源黑体。
- 字重：标题 600，正文 400，数字 600。

| 层级 | 桌面 | 移动 | 行高 | 字距 |
|---|---|---|---|---|
| 满屏主张 | 72px | 40px | 1.08 | -0.03em |
| 首屏主张 | 56px | 34px | 1.1 | -0.02em |
| 模块标题 | 56px | 34px | 1.12 | -0.02em |
| 数字 | 64px | 40px | 1 | -0.03em |
| 正文 | 17px | 16px | 1.55 | 0 |
| 辅助 | 14px | 13px | 1.6 | 0.01em |

- 中文段落最大宽度 34 字（约 620px），禁止通栏长文。
- 最小字号 13px，不再出现 10px 小标。

### 4.4 动效

| 场景 | 参数 |
|---|---|
| 滚动淡入 | 24px 上移 + 透明度，700ms，`cubic-bezier(.22,.61,.36,1)` |
| 首屏进入 | 产品 scale .96→1，900ms |
| 三幕镜头 | 跟随滚动，`scale 1→1.06`，无旋转 |
| 数字滚动 | 600ms，只跑一次 |
| 轮播 | 420ms，拖拽跟手 |
| FAQ | 300ms 高度过渡 |
| hover | 200ms 亮度/透明度变化 |

- 所有动效遵循 `prefers-reduced-motion`，开启后只保留透明度变化。
- 禁止：翻转、弹跳、磁吸、持续漂浮。

### 4.5 三维场景规范

| 层 | 内容 | 视差系数 | 动效 |
|---|---|---|---|
| L0 背景 | 穹顶径向光 + 星尘（≤0.25） | 0.05 | 极慢漂移，可关 |
| L1 中景 | 光锥 / 薄雾 | 0.2 | 随滚动轻微位移 |
| L2 产品 | 显示器 + 界面 + 反射 | 0.5 | 滚动推近 |
| L3 文字 | 标题与说明 | 1.0 | 正常滚动 |

- 光源固定：左上 `--cool`，右下 `--warm`，地面反射用 20% 透明度镜像 + 40px 模糊。
- 产品永远不超出 `rotateX ±5° / rotateY ±8°`。
- 界面截图用 2x WebP，圆角 8px，内部不加发光。

## 五、UX 交互清单

1. **顶栏**：首屏透明，滚过 80vh 后变成 48px 磨砂条，出现「下载」按钮。
2. **滚动**：只有 3.3 一段 sticky，其余正常滚动，避免整页被钉住。
3. **轮播**：按钮 + 拖拽 + 键盘左右键，当前页有 2px 指示线。
4. **FAQ**：点击展开，同时只开一条，展开后自动滚到可视区。
5. **下载**：点击弹出平台选择，移动端直接跳对应商店。
6. **焦点态**：所有可点元素有 2px `--cool` 外框，键盘可完整走通。
7. **移动端**：取消 3D 微倾和 sticky，改为正面截图 + 竖排模块；字号按上表降级。

## 六、技术实现

- **形式**：单页静态站，Vite 构建，原生 HTML/CSS/JS，不引入前端框架。
- **3D**：CSS `transform: perspective()` 做产品微倾与推近；Canvas 只画星尘；**不引入 Three.js**，除非后续确认要真实 3D 模型。
- **滚动**：`IntersectionObserver` 触发淡入；sticky 段用 `getBoundingClientRect` + `requestAnimationFrame` 计算进度，避免 scroll 事件里重排。
- **图片**：界面截图导出 2x WebP，首屏预加载，其余 `loading="lazy"`。
- **性能目标**：LCP < 2.5s，滚动 60fps，首屏 JS < 60KB。
- **可访问性**：语义标签、对比度 ≥ 4.5:1、`prefers-reduced-motion`、键盘可达。

- 不做网格底纹铺满
